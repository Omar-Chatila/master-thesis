# Environment-aware random walks — MSc thesis

A compile-ready LaTeX repository for an interdisciplinary computer-science / movement-ecology thesis. The structure follows the complete workflow from environmental annotation and trajectory segmentation through kernel construction and endpoint-conditioned random walks to utilization distributions and visit probabilities.

## Quick start

Requirements: pdfLaTeX, `latexmk`, and Biber. The optional Tengwar design also uses `ebgaramond`. On Debian/Ubuntu, a typical installation is `texlive-latex-extra texlive-fonts-extra texlive-bibtex-extra biber`.

```bash
make
```

The PDF is written to `build/main.pdf`. During writing, `make watch` rebuilds whenever a source file changes; `make clean` removes generated files.

## First edits

1. Edit the title, supervisors, programme, dates, and draft switch in `config/thesis-meta.tex`.
2. Replace the visible green writing prompts chapter by chapter. Set `\draftmodefalse` before submission to hide any prompts that remain.
3. Add literature to `references.bib` and cite with `\textcite{key}` or `\parencite{key}`.
4. Put graphics in `figures/`, tables generated by scripts in `tables/`, and reproducibility details in `appendices/`.
5. Keep every quantitative result traceable to a data set, configuration, random seed, software revision, and output artifact.
6. Consult `SOURCE_MAP.md` when adapting material from the proposal or coauthored random-walk paper. Keep the thesis pipeline-led and distinguish shared theory from new thesis extensions.
7. Compare or select the visual themes described in `DESIGNS.md`; all themes use identical thesis content.

## Writing conventions

- Use `\ac{ud}`, `\ac{hmm}`, and the other acronym commands after adding any new acronym to `config/thesis-style.sty`.
- Use `\qtyvalue{100}{m}` for lightweight number–unit typesetting without an additional package.
- Use `\placeholder{...}` for a missing paragraph or figure and `\draftnote{...}` for a decision or reminder.
- Prefer vector PDF graphics for plots and diagrams. PNG is appropriate for raster maps. Each figure should remain legible in grayscale and should not rely on red–green contrast alone.
- Labels use prefixes: `chap:`, `sec:`, `fig:`, `tab:`, `eq:`, and `alg:`.
- The references currently included are a curated starting set, not a complete literature review. Verify all bibliographic metadata before submission.
