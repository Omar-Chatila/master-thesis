# Figures

Store final figure assets here. Prefer PDF for vector plots and PNG for raster maps.

For each non-trivial figure, record in its caption or a nearby note:

- the script/notebook that generated it;
- input data and preprocessing version;
- configuration and random seed;
- the repository commit hash;
- whether map layers require attribution.

Suggested names include `pipeline-overview.pdf`, `kernel-examples.pdf`, `ud-comparison.png`, and `runtime-scaling.pdf`.
